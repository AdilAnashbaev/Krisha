# krisha-house-finder

Ищет на [krisha.kz](https://krisha.kz) объявления о продаже домов в Алматы
(Медеуский район, южнее/выше пересечения пр. Абая и пр. Достык — ближе к
горам) и отбирает те, что соответствуют критериям:

- 5–6 комнат
- цена 100 000 000 – 140 000 000 тг
- один этаж
- центральная канализация, центральное водоснабжение, центральное отопление
- свежий ремонт
- есть фотографии

Результат — HTML-отчёт (`output/report.html`) с тремя группами объявлений:
**подходят**, **нужна ручная проверка** (если на странице объявления не
нашлось какое-то поле — чтобы не терять реальный вариант из-за пробела в
парсинге) и **не подходят** (с указанием, какой критерий не совпал).

## ⚠️ Важно про сеть

Это обычный скрипт на Python, который делает HTTP-запросы к krisha.kz —
запускайте его на своей машине (не в этой облачной сессии: здесь исходящий
доступ к krisha.kz заблокирован политикой окружения, поэтому проверить
скрипт вживую я не смог). Логика парсинга проверена офлайн через
`--mock` на сохранённых фикстурах (см. `krisha_finder/tests/`), но реальная
разметка сайта может слегка отличаться — см. раздел «Если сайт изменился».

## Установка и запуск

```bash
cd krisha-house-finder
pip install -r requirements.txt

# посмотреть, какой URL поиска будет использован (без запроса к сети)
python main.py --dry-run

# офлайн-проверка логики парсинга на локальных фикстурах
python main.py --mock

# реальный запуск
python main.py --max-pages 5 --max-listings 60 --output-dir output
```

Откройте `output/report.html` в браузере.

## Параметры

| Флаг | По умолчанию | Описание |
|---|---|---|
| `--price-from` / `--price-to` | 100000000 / 140000000 | Диапазон цены, тг |
| `--rooms-min` / `--rooms-max` | 5 / 6 | Диапазон количества комнат |
| `--max-pages` | 5 | Сколько страниц выдачи поиска просмотреть |
| `--max-listings` | 60 | Максимум объявлений, чьи страницы будут открыты |
| `--delay` | 1.5 | Пауза между запросами, сек (не перегружать сайт) |
| `--no-geo-filter` | выкл | Отключить проверку координат «выше Абая/Достык» |
| `--mock` | выкл | Работать на локальных фикстурах вместо сети |
| `--dry-run` | выкл | Только напечатать URL поиска и выйти |

## Как это работает

1. Строится URL поиска по домам в Медеуском районе Алматы с фильтром
   цены (`das[house.type_object]=1`, `das[price][from/to]` — это реальные,
   подтверждённые параметры фильтра krisha.kz).
2. Со страниц выдачи собираются ссылки на объявления (`/a/show/<id>`).
3. Для каждого объявления открывается страница объявления и из таблицы
   характеристик (`dl.a-parameters`, пары `dt`/`dd`) вытаскиваются:
   количество комнат, этажность дома, состояние (ремонт), отопление,
   водоснабжение, канализация, координаты дома.
4. Гео-фильтр «выше пересечения Абая/Достык» — это приблизительная
   прямоугольная область (южнее линии Абая, в сторону гор). Координаты
   заданы в `krisha_finder/config.py` (`DEFAULT_GEO_BOX`) — при
   необходимости подкорректируйте их на карте (2ГИС/Яндекс.Карты).
5. Комнаты/цена дополнительно проверяются по факту (не только по URL),
   т.к. точный синтаксис `das[live.rooms]` для диапазона не подтверждён
   на 100%.

## Если сайт изменился

Krisha.kz время от времени меняет вёрстку. Если отчёт стал пустым или
все объявления попадают в «нужна ручная проверка»:

1. Откройте `--dry-run` URL в браузере, откройте любое объявление и
   посмотрите исходный код страницы (Ctrl+U).
2. Проверьте, что таблица характеристик по-прежнему имеет класс,
   содержащий `parameters` (селектор `dl[class*='parameters']` в
   `krisha_finder/parse_detail.py`), а заголовок — `h1` внутри
   `.a-header-wrapper`.
3. Обновите селекторы в `parse_detail.py` при необходимости и повторно
   запустите `python -m unittest discover -s krisha_finder/tests` —
   тесты должны использовать те же фикстуры, обновите и их при желании.

## Этичность использования

Скрипт делает обычные GET-запросы с паузой между ними и не пытается
обходить какую-либо защиту от ботов — если krisha.kz отдаёт капчу или
блокирует запросы, скрипт остановится с понятной ошибкой (используйте
`--dry-run`, чтобы открыть тот же поиск руками в браузере). Инструмент
предназначен для личного подбора недвижимости, а не для массового сбора
данных.
